## 启动和使用

发布目录为 release，运行其中的 waist_motor_controller.exe。依赖 Windows x64、.NET 10 Desktop Runtime 和原有 ZLG USBCANFD-200U 驱动；ControlCANFD.dll 必须与 exe 同目录。发布包使用项目原有的 x64 驱动 DLL。

1. 确认 USB-CANFD 的设备索引及通道（从0开始），点击“打开设备”。通信固定为标准 CANFD+BRS，仲裁1M、数据5M，终端电阻开启。
2. 等待 ID 3/4/5/6 的在线状态。程序通过 SDO 0x100A 分段读取真实软件版本；预期版本单独显示，读取失败会显示“未读到”。
3. 选择一个电机，点击“使能”。使能指令保持当前反馈位置，150ms 后允许运动。
4. “运行到角度”：输入关节输出端绝对角度，点击执行。角度以电机当前零位为基准。
5. “− 点动 / + 点动”：每点击一次，以最新反馈角度为起点，移动指定负/正增量。例如当前位置20°、增量1°，正向点动目标为21°。运动期间拒绝叠加另一条定位或增量指令；增量运动还会检查上一目标是否到达。
6. “停止 / 保持”终止轨迹并持续保持最后指令位置。切换到其他窗口也会停止正在生成的轨迹。此按钮保持使能，不代表失能抱闸。
7. “急停：4台电机”撤销本程序所有轨迹，再分别向四个配置节点发送失能抱闸帧；“关闭设备”和退出程序也会执行这个流程。软件只能确认发送结果，不能据此保证机械已经停止。
8. 参数和映射需关闭设备后点击“保存映射”保存。

速度和加速度是**关节输出端**的 rpm、rpm/s，由主机生成轨迹；反馈速度则是**电机输入端** rpm。默认速度1rpm、加速度5rpm/s、增量1°。点动增量范围0.01°~30°，UI绝对角度范围±178.90°。这是协议计数范围的边界保护，不是各关节的机械可用行程；首次真机测试应从1°小步确认方向和行程。

## 协议修正

旧工程自定义 PDO 的布局不能继续使用：

- 单轴帧 0x100+ID，CANFD+BRS，7字节，大端。B0 的使能为 bit7、抱闸释放为 bit6、模式为 bits5..4、错误复位为 bit3。位置保持控制字为 D0，清错为08，失能为00。
- B1..2 为输出端位置 int16；B3..4、B5..6 为电流/电流前馈，不再写速度与加速度。当前定位控制中两组电流字段都为0。
- 新反馈有11个有效字节，CANFD线长为12字节：B0..1位置、B2..3输入端速度、B4..5电流、B6状态、B7..8故障、B9..10温度。B6 bits7..6为模式、bit5使能、bit4抱闸释放、bit3故障。
- 新故障码按 B7 | B8<<8 组合；新增布局中 0x0800 为CAN通信故障。EMCY 0x80+ID 也会撤销对应控制。
- 新协议未提供温度缩放因子，UI显示原始温度值；也没有真实到位位或力矩反馈，界面到位灯基于反馈位置误差≤20cnt和输入端速度≤2rpm估算，不冒充硬件状态。
- 位置沿用65536cnt/圈（参考旧项目）；新PDF使用int16并建议距离两端留200cnt，因此软件目标范围为±32568cnt。真机仍需核对实际角度比例。
- 程序不使用0x200多控广播，所有运动、清错、标零、改ID和急停都限定到保存映射的四个ID。0x80只查询反馈，总线上另外两台电机会响应这个查询。
- SDO匹配检查节点、对象索引/子索引、命令类型；软件版本读取支持60/70交替分段。接收端同时处理经典CAN和CANFD；默认SDO发送采用CANFD+BRS。

## 轨迹、停止与故障

新版自定义位置模式是同步位置模式。程序用独立线程按约1ms唤醒周期生成带加减速的同步位置指令，持续发送保持指令以维持通信。每帧位置变化≤90cnt，小于PDF记载的100cnt跃迁阈值；调度延迟时只推进最多5ms的轨迹时间，不一次追赶全部延迟。

Windows/.NET/USB-CAN不是硬实时链路，**没有保证精确1000Hz**。该实现适合低速上位机调试；若应用需要严格1kHz同步，应由实时控制器或设备硬件周期发送实现。

以下情况撤销轨迹并尝试向对应节点发送失能：反馈超过500ms未更新、反馈/EMCY故障、发送失败、已过使能保护期但电机仍未使能或未释放抱闸。发送与撤销共用调度锁，防止急停后重发旧使能帧。急停发送失败会显示失败，不报告成功。

## 标零

仅在本程序已使能、停止并到位后执行“当前位置设零”。流程为：撤销旧位置发送 → SDO 0x2531=1 → 失能抱闸 → SDO 0x2531=0复位 → 同步查询并验证新鲜零位反馈。结束保持失能，由操作者手动重新使能。超时/拒绝不算成功；急停或失能会取消尚未完成的后续写入。

## 配置迁移

配置位于 exe 旁的 config/motors.json。

- 首次无配置时使用3/4/5/6。
- 旧版未带SchemaVersion或版本低于2的配置，如果四个逻辑关节恰好为11/12/13/14，会先备份为 motors.json.pre-v2.bak，再迁移为3/4/5/6。
- 自定义旧ID保留；旧速度参数单位不同，迁移时恢复新版低速默认值。
- 已保存的新版配置不再自动改ID。运行时控制使用保存后的注册表，编辑框中的未保存值不参与发帧；连接期间不能改映射。

## V1.17实机适配（2026-11-03）

实机只读核对确认，R120 V1.17.12与R120MAX V1.17.13当前输出的12字节反馈仍为原工程布局，与提供PDF中的B6状态布局不同。ID3实测反馈00A00000FFE9000001130210；同时读取3/4/5/6的SDO603F均为0000。之前将温度字节01误读成0100故障，错误禁用了使能按钮。
